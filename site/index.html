Features

Everything pi does, in a window you can see at a glance.

⌘1 … ⌘9

Sessions side by side

Projects and their sessions sit in a sidebar. Every open session runs its own pi, so switching never stops work.

Session tree

Walk the branches of a session with the keyboard, jump back to any message and summarize the branch you leave.

/fork

Fork from any message

Try another direction from any point. The original session stays as it was.

Extension commands, prompt templates and skills from pi, plus /compact, /model, /name, /copy, /export and more.

Paste or drop files into the message field. They become chips and are sent as paths, the same way pi does it in the terminal.

Y / N

Questions in the chat

When an extension asks something, the question shows up in the transcript. Pick with a click, a digit or the arrows.

⌘⇧M

Model per session

Switch model and thinking level for one session without touching pi's defaults.

auto

Updates that wait for you

The app updates itself. Updates for pi and its extensions show next to the version and run only when you click.

How it works

The agent stays in pi. The app is the window.

Pi GPUI starts pi --mode rpc as a child process for each session and talks to it in JSON lines. There is no SDK wrapper, no second agent loop and no copy of pi inside the app. Whatever works in your terminal works here: models, providers, extensions, skills, prompt templates.

The interface is GPUI, the framework behind the Zed editor. Text, code and the transcript are drawn with Metal, so long sessions scroll without stutter.

Extensions

Can it run DOOM?

Yes. pi calls a doom tool, and a plugin draws a playable Freedoom right in that message. Click it to play, Esc gives the keyboard back. Ask again and the game moves to the new message.

DOOM is just the loudest example. The same pieces work for anything:

  • pi extensionsTools, commands, skills and prompt templates you already use with pi work here unchanged. Their questions show up in the chat.
  • app pluginsA folder with plugin.json and a program in any language, talking JSON lines. Add buttons to the message field, keybindings, status in the title bar.
  • live viewsA plugin streams frames into a tool call and gets the keys while you play. Games today, charts and previews tomorrow.

  }

FAQ

Questions

What is Pi GPUI?

A native macOS interface for the pi coding agent. It starts your installed pi in RPC mode and shows projects, sessions, tool calls and answers in one window.

Is it an alternative to the Claude Code app?

If you want a desktop app for agentic coding, yes. Pi GPUI is a GUI for pi, an open coding agent that works with Claude and other providers. You keep pi's models, extensions and skills and get a native Mac window around them.

Is it written in Rust?

Yes. Rust on GPUI, rendered with Metal. pi stays the agent engine, the app talks to it over JSON lines.

Do I need pi installed?

Yes, pi 1.4 or newer within 1.x. The app finds it in PI_EXECUTABLE, PATH or your login shell, so nvm installs work. It never installs or updates pi on its own.

Which Macs does it run on?

Macs with Apple silicon. New versions arrive through GitHub releases, and the app offers "Restart to update" when one is ready.

Is it free?

Yes. Free to download, source on GitHub.
