Get started

Running in a minute.

1

Install pi

Skip this if pi already runs in your terminal.

$ curl -fsSL https://pi.dev/install.sh | sh
2

Log in

Connect a subscription or an API key. pi keeps it, the app never reads it.

$ pi
> /login
3

Open Pi GPUI

Move it to Applications and open it. It finds pi on its own, nvm installs included, and lists your projects and sessions.

How it works

Each session runs your own pi.

For every session the app starts your installed pi with pi --mode rpc and talks to it over stdin and stdout. Nothing sits in between and no copy of pi ships inside the app, so whatever works in your terminal works here too.

The interface is built with GPUI, the framework behind the Zed editor, and drawn with Metal. Long sessions full of code scroll without stutter.

FAQ

Common questions

What is Pi GPUI?

A Mac app for the pi coding agent. It runs the pi you have installed and shows your projects, sessions, tool calls and answers in one window.

Is it an alternative to the Claude Code app?

If you want a desktop app for coding with an agent, yes. pi is an open coding agent that works with Claude and other providers, and Pi GPUI gives it a native Mac window. Your models, extensions and skills stay the same.

Is it written in Rust?

Yes, Rust with GPUI, drawn with Metal. The agent itself is pi, and the app talks to it over JSON lines.

Do I need pi installed?

Yes, pi 1.4 or newer within 1.x. The app finds it in PI_EXECUTABLE, PATH or your login shell, so nvm installs work. It never installs or updates pi on its own.

Which Macs does it run on?

Macs with Apple silicon. Releases are signed and notarized by Apple, so macOS opens them without a warning. New versions arrive through GitHub releases, and the app offers "Restart to update" when one is ready.

Is it free?

Yes. It is open source under the MIT license, with the source on GitHub. You only pay your model provider.
