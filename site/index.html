Pi GPUI runs your installed pi coding agent in a native desktop app for macOS and Linux. Your models, extensions, skills and sessions are ready at launch. It's written in Rust with GPUI and drawn on the GPU.

Get started

Install in three steps.

1

Install pi

Skip this if pi 1.4 or newer is already installed.

$ curl -fsSL https://pi.dev/install.sh | sh
2

Log in

Connect a subscription or an API key. pi keeps it, the app never reads it.

$ pi
> /login
3

Open Pi GPUI

It finds pi on its own, nvm installs included, and lists your projects and sessions.

macOS, or download the app

$ brew install --cask bytesbay/tap/pi-gpui

Linux, x86_64 and arm64 (beta)

$ curl -fsSL https://pi-gpui.dev/install.sh | sh

Features

Made for working with pi all day.

⌘1 … ⌘9

Sessions side by side

Projects and sessions live in the sidebar, open sessions in tabs. Each one has its own pi, so one keeps working while you are in another.

⌘⇧T

Session tree

See every branch of a session and jump back to any message from the keyboard. pi can summarize the branch you leave.

/fork

Fork from any message

Try a different direction from any message. The original session stays untouched.

/

Slash commands

Your extension commands, prompt templates and skills, plus /compact, /model, /name, /copy, /export and more.

drop · paste

Files and images

Paste or drop files and screenshots into a message. pi gets their paths, as in the terminal.

◔ 42%

Context ring

A ring by the model name shows how full the context is and when pi will compact. Click it for cache hits and plan limits.

Y / N

Questions in the chat

When an extension asks you something, it shows up as a card in the chat. Answer with a click, a number or the arrow keys.

⌘⇧M

Model per session

Change the model or thinking level for one session. pi's defaults stay as they are.

auto

Updates on your terms

The app updates itself. New versions of pi and your extensions show up next to the pi version and install only when you click.

How it works

Each session runs your own pi.

For every session the app starts your installed pi with pi --mode rpc and talks to it over stdin and stdout. No copy of pi ships inside the app. It loads one small extension for session tree navigation and usage numbers. Extension questions work inline; extension status lines and widgets are not shown yet.

The interface is built with GPUI, the framework behind the Zed editor, and drawn with Metal on macOS and Vulkan on Linux.

FAQ

Common questions

What is Pi GPUI?

A desktop app for the pi coding agent, for macOS and Linux. It runs the pi you have installed and shows your projects, sessions, tool calls and answers in one window.

Is there a GUI for pi?

Yes. Pi GPUI is a free native GUI for pi on macOS and Linux, written in Rust with GPUI, without Electron or a webview. Web, Electron, Tauri and editor options also exist, and awesome-pi-agent lists them.

Can I use Claude models?

Yes, if your pi is set up for them. pi works with Claude and other providers, and Pi GPUI runs your pi with its models, extensions and skills as they are.

Is it written in Rust?

Yes, Rust with GPUI, drawn with Metal on macOS and Vulkan on Linux. The agent itself is pi, and the app talks to it over JSON lines.

Do I need pi installed?

Yes, pi 1.4 or newer within 1.x. The app finds it in PI_EXECUTABLE, PATH or your login shell, so nvm installs work. It never installs or updates pi on its own.

Which systems does it run on?

macOS 13 or newer on Apple silicon. Mac releases are signed with a Developer ID certificate and notarized by Apple.

Linux on x86_64 and arm64, on X11 and Wayland. It needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36) and a Vulkan driver. The Linux app is in beta: so far it was tested on Ubuntu 24.04 in a VM, so tell us how it runs on your setup. Shortcuts use Ctrl where the Mac app uses ⌘.

On both, new versions arrive through GitHub releases, and the app offers "Restart to update" when one is ready. Windows isn't supported.

Is it free?

Yes. It is open source under the MIT license, with the source on GitHub. You only pay your model provider.
