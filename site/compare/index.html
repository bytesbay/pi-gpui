Desktop apps for the pi coding agent

The pi coding agent runs in the terminal, and several apps give it a window. pi-gui, PI-Desktop, Pi Desktop and PiDeck are built with Electron. Orbit and Pi GPUI are native Rust apps on GPUI, the framework behind the Zed editor. Pi Web runs in your browser.

Pi GPUI is ours, so keep that in mind. The table and descriptions come from each project's README and release downloads, checked on 18 November 2026; the measurements further down are ours, from 8 November. If something is wrong or out of date, open an issue and we'll fix it.

What each one focuses on

pi-gui
pi-gui runs agents in parallel threads, each in its own git worktree if you want. Its Review tab stages changes file by file, and it has a terminal, a file explorer and an editor.
PI-Desktop
PI-Desktop has plugins that add panels, tools, MCP servers, themes and background services, plus subagents and parallel worker sessions.
Pi Desktop
Pi Desktop works with pi and oh-my-pi. It has Mission Control for background work, tasks in isolated git worktrees, linked tasks across several repositories, a subagents panel, a terminal and voice dictation.
PiDeck
PiDeck manages pi, DSH (DeepSeek Harness) and ACP agents and imports local Codex and Claude sessions, with git integration and a built-in terminal.
Orbit
Orbit is a native GPUI workbench: chat, review and commit in one window, and an attachment tray for images, files and long pastes. It has builds for Apple silicon and Intel Macs, Windows and Linux.
Pi Web
Pi Web is a browser UI that uses pi's own config and session files. It can branch from an earlier message, switch git worktrees, and manage providers, models and skills from the web.
Pi GPUI
Pi GPUI is built around pi's session tree, with forks from earlier messages. Extension questions are answered inside the chat, plugins can be written in any language, and Zed themes work as they are.

Size and memory

We measured Pi GPUI and three Electron apps on 8 November 2026 on an M1 Pro (Apple silicon builds), each with no projects open. Memory counts each app's own processes, without the pi and node processes they start. Window time favors Electron apps, which can show a window before the page has loaded. Which one to pick

  • On Windows: Orbit, pi-gui, PI-Desktop, Pi Desktop or PiDeck. Pi GPUI doesn't run there.
  • On an Intel Mac: Orbit, PI-Desktop or PiDeck.
  • In a browser, on any system: Pi Web.
  • Worktrees and a terminal inside the app: pi-gui or Pi Desktop.
  • Plugins with their own panels and MCP servers: PI-Desktop.
  • Imported Codex or Claude sessions, or DSH and ACP agents, next to pi: PiDeck.
  • The session tree and forks in a native app on Apple silicon or Linux: Pi GPUI. The other native GPUI app, with Windows and Intel Mac builds, is Orbit.

This list isn't complete. awesome-pi-agent lists more GUIs, editor plugins and web UIs for pi.
